# Flowday – To-Do List Management System

Flowday is a task management web application designed to help users organize daily tasks, manage projects, and track their progress.

## Features

- User registration and login
- Task management
- Task priorities
- Due dates and times
- Important and starred tasks
- Project and tag organization
- Progress tracking

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python Flask
- **Database:** MySQL

## Project Structure

- `app.py` – Flask backend
- `home.html` – Home page
- `index.html` – Task dashboard
- `login.html` – Login page
- `register.html` – Registration page
- `settings.html` – Settings page
- `schema.sql` – Database schema

## How to Run

1. Install Python and MySQL.
2. Install the required Python packages.
3. Configure your local database and environment variables.
4. Run the Flask application using `python app.py`.
5. Open the local address shown in the terminal.

## Project Purpose

Flowday was developed as a college mini-project to demonstrate web development, backend programming, database integration, and task management.
